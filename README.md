### 状态码：让 HTTP 语义说话

| 状态码          | 语义            | 典型场景                      |
| --------------- | --------------- | ----------------------------- |
| 200 OK          | 成功            | 查询、更新成功                |
| 201 Created     | 资源已创建      | POST 创建成功（默认应改成它） |
| 204 No Content  | 成功但无响应体  | DELETE 删除成功               |
| 400 Bad Request | 请求本身有误    | 业务规则不满足                |
| 单元401 / 403格 | 未认证 / 无权限 | 123                           |
| 404 Not Found   | 资源不存在      | 按 ID 查询落空                |
| 409 Conflict    | 资源冲突        | 用户名已存在                  |
| 422             | 参数校验失败    | FastAPI 自动返回              |
